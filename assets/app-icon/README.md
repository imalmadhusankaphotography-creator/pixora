# PIXORA app icon

A dark rounded tile (`#1b1530` → `#0e1a24`) with a "P" stroke in PIXORA's gradient
(`#8f6bff` → `#5a7dff` → `#22d3ee`), a cyan dot and a white spark. 512-unit tile, `rx=112`,
clipped like PhotoCraft's so the importer test still finds the rounded-square vector mask.

The PNGs and the .ico are rendered from `photocraft.svg` (Windows/Linux renders crop 22 units off
each side; the 1024 px render is padded onto Apple's icon grid). License: `LICENSE.txt`.
