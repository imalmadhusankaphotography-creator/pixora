PIXORA app icon (photocraft.svg, photocraft-small.svg and every file derived from them in this
directory: photocraft-1024.png, photocraft.ico, hicolor/). The file names are kept from PhotoCraft so
the code that loads them is unchanged; photocraft.icns is still PhotoCraft's (macOS only, unused by
the Windows build).
